# കാപ്പിയും പാട്ടും (Kappiyum Paattum)

## Vision
Create a nostalgic digital Kerala tea shop experience inspired by Deluxe Saloon.
The website is not a music player. The website is a feeling.

## Core Experience
Open website → See nostalgic tea shop scene → Music starts → Feel transported to another time.

## MVP
- Full-screen hero illustration
- YouTube playlist playback
- Kerala time
- Custom player UI
- Vercel deployment

## Tech Stack
React, Vite, Tailwind, YouTube Iframe API, Firebase, Vercel
